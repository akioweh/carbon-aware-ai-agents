# Global Project Coding Style

This document defines the high-level coding standards for the entire
`carbon-aware-ai-agents` project. For component-specific guidelines, refer to
the respective component's `CODING_STYLE.md` (e.g., `scheduler/CODING_STYLE.md`
for the Scheduler component).

## Documentation

### Markdown

Use `prettier` for to format all markdown files. The config file makes it wrap
prose nicely.
